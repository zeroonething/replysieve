# Master roadmap

## replysieve

| Version | Outcome | Detail | Status |
| --- | --- | --- | --- |
| 0.1.0 | A developer or an agent (Claude Code, Codex) judges one comment or a batch from the CLI or MCP and gets approve, reject or needs-review with a reason, at light, medium or heavy strictness, using a built-in preset or their own rules, through a decision model on OpenRouter, with accuracy shown on a labeled test set. Installable with cargo install. | specified | released |
| 0.2.0 | An app (launchladder first) moderates every comment as it is submitted by calling a self-hosted replysieve HTTP server, with a Docker image and a quick-start guide. | outline | planned |
| 0.3.0 | A community owner tests their own rules against their own example comments before going live, sees which rule fired on each one, and follows recipes for Reddit mod queues, Discord and website comment forms. | outline | planned |
| 0.4.0 | Anyone installs replysieve in one step through Homebrew, the MCP server registry or a prebuilt binary for macOS, Linux and Windows. | hypothesis | planned |
